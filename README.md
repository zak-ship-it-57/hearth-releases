# Hearth downloads

Hearth is an end-to-end encrypted chat app for Windows: messages, voice and video calls, screen sharing, and watching videos together.

This repository holds only the installers. **Get the latest from [Releases](https://github.com/zak-ship-it-57/hearth-releases/releases/latest):**

- **Hearth-Setup-x.y.z.exe**: installs Hearth and keeps it up to date by itself.
- **Hearth-Portable-x.y.z.exe**: runs without installing, but doesn't update itself.

Windows may warn that the installer is from an unknown publisher, because it isn't code-signed yet. Choose **More info → Run anyway**.

To join friends, open the invite link they sent you after installing.
